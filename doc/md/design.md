# 미리봄 디자인 가이드

> 사람이 몰리기 전, 온라인 관심을 먼저 봅니다.

이 문서는 미리봄의 브랜드(컨셉·무드·보이스)와 디자인 시스템(컬러·타이포·컴포넌트)을 정한다.
화면을 만들거나 문구를 쓸 때 여기 적힌 규칙을 기준으로 한다.

---

## 1. 브랜드 컨셉

### 이름과 로고가 말하는 것

| 요소 | 뜻 |
|---|---|
| **미리 봄** | 사람이 오기 전에 *미리 본다*. 서비스가 하는 일 그 자체 |
| **망원경 심볼** | 멀리, 먼저 내다보는 시선. 감시 카메라가 아니라 *관측* |
| **새싹 잎** | '봄'의 두 번째 뜻. 아직 커지지 않은 **조짐(싹)** 을 알아챈다 |
| **하늘색 그라데이션** | 맑은 시야, 부산의 바다와 아침 하늘 |

한 줄로: **"싹이 보일 때 먼저 알아채는 관측소."**

### 우리가 아닌 것 (`subject.md` 기준)

- 사람 수를 세는 시스템이 아니다 → 카메라·감시 이미지 쓰지 않는다
- 관광 홍보가 아니다 → '핫플', '인기 급상승' 같은 말과 순위 UI를 쓰지 않는다
- 재난 사이렌이 아니다 → 빨간색을 평소 화면에 깔지 않는다. 위험은 필요한 곳에만 표시한다

## 2. 무드

**차분한 아침 관측소.** 매일 07:00 판정이 나오는 시각의 맑고 조용한 분위기.

| 키워드 | 화면에서 이렇게 |
|---|---|
| **맑음** | 흰 바탕, 넓은 여백, 하늘색 한 가지가 중심 |
| **정확함** | 얇은 1px 선, 고정폭 숫자, 단위와 기준 시각을 항상 함께 |
| **침착함** | 경보 색은 데이터에만. 큰 경고 배너·깜빡임·흔들림 없음 |
| **믿을 수 있음** | 추정치는 추정치라고 쓴다. 근거를 숫자와 문장으로 보여준다 |

**레퍼런스 감도:** 기상청 예보 화면의 정보 밀도 + 공공 디자인 시스템의 절제 + 로고의 부드러운 곡선(로고에만).

**피하는 무드:** 관제실 다크 모드, 네온, 큰 빨간 경고, 귀여운 캐릭터 일러스트, 관광 앱 같은 사진 위주 화면.

## 3. 보이스 & 톤

### 공통 원칙

1. **숫자와 근거 먼저.** "많이 늘었어요" 대신 "평소보다 4.2배"
2. **추정은 추정이라고.** 예측값에는 항상 `추정치`·`예상`·기준 시각을 붙인다
3. **겁주지 않는다.** 공포가 아니라 *준비*와 *선택*을 돕는 말
4. **몰리게 만들지 않는다.** 시민에게 순위·인기·화제성 표현을 쓰지 않는다

### 대상별 톤

| | 관리자·협력기관 (웹) | 시민 (모바일) |
|---|---|---|
| 말투 | 합니다체, 짧은 보고서 문장 | 해요체, 권유형 |
| 역할 | 판단 근거를 주는 **분석 보고** | 다른 선택지를 주는 **친절한 예보** |
| 예시 | "검색이 평소보다 4.2배 많고 3일 연속 오르고 있습니다. 2단계로 판정했습니다." | "주말에는 붐빌 것 같아요. 오늘 오전이나 다음 주 평일에 방문해 보세요." |
| 정보 양 | 수치·범위·기준선 모두 표시 | 4단계 혼잡 라벨 + 추천 한 줄 |

### 쓰는 말 / 안 쓰는 말

| 쓰는 말 | 안 쓰는 말 | 이유 |
|---|---|---|
| 혼잡 예상, 붐빔 | 인기, 핫플, 화제, 급상승 TOP | 시민을 더 몰리게 함 |
| 판정, 단계, 근거 | 위험!, 긴급!, 대참사 | 과장·공포 조장 |
| 예상 방문객 3.1만~4.6만 | 약 4만 명 몰림 확실 | 범위와 불확실성 표시 |
| 추정치 · 현장 확인 전 | (표시 없음) | 신뢰 |
| 방문해 보세요, 이용해 주세요 | 가지 마세요, 금지 | 선택을 존중 |
| 관심 · 주의 · 경계 (1·2·3단계) | Lv.1, 레드 경보 | 공공 용어와 맞춤 |

### 고정 문구

- 시민 추정치 안내: **"이 정보는 검색량, 블로그, 뉴스 등 온라인 관심도를 바탕으로 예측한 추정치로, 실제 현장 혼잡과 다를 수 있습니다."**
- 관리자 추정치 배지: **`추정치`** (현장 확인 전 값에 항상)
- 판정 시각 표기: **`09.21 07:00 판정`**

## 4. 브랜드 컬러

로고의 **하늘색**과 **새싹 연두**에서 시작하고, 글자는 깊은 **바다 네이비**로 잡는다.

### 브랜드 기본색

| 토큰 | HEX | 출처 / 쓰임 |
|---|---|---|
| `navy-900` | `#1B2F4A` | 바다 네이비. 제목·본문·차트의 실측 막대·구분선 강조 |
| `sky-300` | `#A6D8F4` | **메인 브랜드색.** 로고 그라데이션 끝색. 주요 버튼·선택 상태·검색 테두리 |
| `sky-50` | `#EAF5FC` | 연한 하늘. 추천 박스, 예측 범위 영역, 호버 |
| `sky-700` | `#1F6FA3` | 링크·포커스 링·하늘색 위 강조 텍스트 (흰 바탕 5.4:1) |
| `sprout-200` | `#E2F4BF` | 로고 새싹 잎. **아껴 쓴다**: '신규' 배지, 별칭 등록 완료 등 "새로 돋아난 것" |
| `sprout-800` | `#3F6212` | 새싹 배경 위 텍스트 (6.0:1) |

로고 그라데이션: `linear-gradient(180deg, #FFFFFF 0%, #A6D8F4 100%)` (V2.6 기준, 어두운 배경 위)

### 중립색

| 토큰 | HEX | 쓰임 |
|---|---|---|
| `white` | `#FFFFFF` | 기본 배경 |
| `gray-50` | `#F6F8FA` | 섹션 배경, 사이드바 |
| `gray-100` | `#EEF1F4` | '보통' 배지 배경, 비활성 바 |
| `gray-200` | `#DDE3E9` | 1px 테두리·구분선 |
| `gray-500` | `#5A6B80` | 보조 텍스트, 캡션, 축 라벨 (5.5:1) |
| `gray-400` | `#8A96A3` | 비활성·플레이스홀더 전용 (본문 텍스트 금지, 3.0:1) |

### 경보 단계 (관리자)

`subject.md`의 관심→주의→경계를 `FSD.md`의 1·2·3단계에 그대로 맞춘다.

| 단계 | 이름 | 채움색 | 텍스트색 | 연한 배경 |
|---|---|---|---|---|
| 판정 보류 | – | `#8A96A3` | `#4B5867` | `#EEF1F4` |
| 1단계 | 관심 | `#4FBFAE` | `#1F7F72` | `#E3F5F2` |
| 2단계 | 주의 | `#F2B33D` | `#8A5A00` | `#FCEFD2` |
| 3단계 | 경계 | `#E0533D` | `#A93320` | `#FBE4DF` |

- 채움색은 점·막대·지도 마커·작은 사각 표시(■)에만. 텍스트는 반드시 텍스트색을 쓴다
- 단계는 **색만으로 구분하지 않는다** — 항상 "2단계" 글자를 같이 쓴다 (색약 대응)

### 혼잡 4단계 (시민)

| 단계 | 배경 | 텍스트 | 막대 |
|---|---|---|---|
| 여유 | `#EAF5FC` | `#1F6FA3` | `#A6D8F4` |
| 보통 | `#EEF1F4` | `#4B5867` | `#A6D8F4` (일부만 채움) |
| 붐빔 | `#FCEFD2` | `#8A5A00` | `#F2B33D` |
| 매우 붐빔 | `#FBE4DF` | `#A93320` | `#E0533D` |

시민 화면에서는 '여유'를 브랜드 하늘색으로 둬서, 평소 화면이 맑게 보이게 한다.

### 차트 색

| 계열 | 표현 |
|---|---|
| 검색 급증 배수 (우축) | `sky-300` 실선 2px → 대비가 약하면 `#5BAEE0` |
| 실측 방문객 | `navy-900` 막대 |
| 예측 중앙값 | `navy-900` 점선 + 흰 원 마커 |
| 예측 범위 | `sky-50` 영역 (불투명도 100%) |
| 병목 기준선 (5명/㎡) | `#E0533D` 1px 실선 + 라벨 |
| 판정 시점 | `navy-900` 세로 실선 + `09.21 07:00 판정` |

## 5. 타이포그래피

| 역할 | 폰트 | 비고 |
|---|---|---|
| 한글 UI | **Pretendard** (대체: Apple SD Gothic Neo, Noto Sans KR) | 모든 제목·본문 |
| 숫자·시각·영문 라벨 | **IBM Plex Mono** (대체: JetBrains Mono, monospace) | `×4.2`, `3.8만`, `09.21 07:00`, `BEYOND ONLINE MONITORING` |
| 로고 | 워드마크 이미지만 사용 | 둥근 로고체를 UI 텍스트로 흉내 내지 않는다 |

### 스케일

| 토큰 | 크기 / 행간 | 굵기 | 쓰임 |
|---|---|---|---|
| `display` | 32 / 42 | 700 | 로그인 메인 카피, 시민 첫 화면 |
| `h1` | 28 / 36 | 700 | 장소명 (북항친수공원) |
| `h2` | 20 / 28 | 700 | 페이지 제목 |
| `h3` | 16 / 24 | 700 | 섹션 제목 (추이 그래프, 판정 근거) |
| `body` | 15 / 24 | 400 | 판정 문장, 본문 |
| `body-sm` | 13 / 20 | 400 | 표 셀, 보조 설명 |
| `caption` | 12 / 16 | 400 | 축 라벨, 기준 시각, 안내문 |
| `metric-lg` | 28 / 32 | 500 mono | 상단 핵심 지표 (`×4.2`, `3.8만`) |
| `metric` | 14 / 20 | 400 mono | 표 안 숫자 |

- 숫자는 `font-variant-numeric: tabular-nums`로 자릿수를 맞춘다
- 단위는 숫자보다 한 단계 작게: `3.8`**만**, `3.8`**명/㎡**
- 강조는 굵게만. 밑줄은 링크에만, 기울임은 쓰지 않는다

## 6. 레이아웃 · 형태

### 간격 (4px 기준)

`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64`

- 관리자 웹: 1440 기준, 좌측 사이드바 152~240px, 콘텐츠 여백 24px, 12단 그리드 / 거터 24px
- 시민 모바일: 375 기준, 좌우 여백 24px, 하단 탭바(검색 · 지도) 64px

### 형태 규칙

| 항목 | 값 | 이유 |
|---|---|---|
| 모서리 | 버튼·입력·카드 `2px`, 배지 `2px` | 데이터 화면은 각지게, 정확한 인상 |
| 테두리 | `1px gray-200` 기본, 섹션 제목 아래 `1px navy-900` | 와이어프레임의 얇은 선 감도 유지 |
| 그림자 | 쓰지 않음 (모달만 `0 8px 24px rgba(27,47,74,.12)`) | 평평하고 맑게 |
| 아이콘 | 1.5px 선 아이콘, 모서리 둥글게 | 로고 곡선과 연결되는 유일한 지점 |
| 그래픽 모티프 | 하늘색 얇은 **물결선**, 점선 **동심원(레이더)** | 바다(부산) + 멀리 내다봄. 로그인·빈 화면에만 |

로고의 둥근 곡선은 로고와 아이콘에만 남기고, UI는 각진 정보 화면으로 대비시킨다.

## 7. 컴포넌트

### 버튼

| 종류 | 스타일 |
|---|---|
| Primary | 배경 `sky-300`, 글자 `navy-900` 700, 높이 44 (모바일 48) |
| Secondary | 배경 흰색, 테두리 `navy-900` 1px, 글자 `navy-900` |
| Text link | `sky-700` 또는 `navy-900` + 밑줄 |
| Disabled | 배경 `gray-100`, 글자 `gray-400` |

- Hover: Primary → `#8CCBEF`, Secondary → 배경 `sky-50`
- Focus: `2px sky-700` 외곽선, 2px 간격

### 입력

- 높이 44, 테두리 `gray-200`, 포커스 시 `sky-300` 2px
- 시민 검색창은 처음부터 `sky-300` 테두리 + 돋보기 아이콘(`sky-300`)
- 라벨은 입력 위 `caption`, 도움말은 아래 `caption gray-500`

### 세그먼트 선택 (소속 기관)

- 선택: 배경 `sky-300`, 라디오 채움 `navy-900`
- 비선택: 흰 배경, 테두리 `navy-900` 1px

### 배지

| 배지 | 스타일 |
|---|---|
| 경보 단계 | `■` 채움색 사각 + "2단계 · 09.21 07:00 판정" |
| 혼잡 (시민) | 4단계 표의 배경·텍스트색 |
| 신규 | 배경 `sprout-200`, 글자 `sprout-800` |
| 별칭 | 흰 배경 + `sky-300` 테두리 (`부캉이 신규`) |
| 추정치 | 흰 배경 + `navy-900` 점선 테두리 |

### 지표 묶음 (장소 상세 상단)

라벨(`caption gray-500`) 위, 값(`metric-lg`) 아래. 세로 구분선 `gray-200`.
기준을 넘는 값만 해당 단계 텍스트색으로 바꾼다.

### 표 (급상승 장소 · 우선 대응 목록)

- 헤더: `caption gray-500`, 아래 `1px navy-900`
- 행: 높이 64, 아래 `1px gray-200`, 호버 `sky-50`
- 숫자 열은 오른쪽 정렬 + mono

### 3일 혼잡 바 (시민)

- 3칸 막대, 칸 사이 2px 흰 간격
- 여유 1칸 / 보통 2칸 / 붐빔 3칸(주황) / 매우 붐빔 3칸(빨강)
- 오른쪽에 라벨 텍스트를 반드시 같이

### 안내 박스

| 종류 | 스타일 |
|---|---|
| 방문 추천 | 배경 `sky-50`, 작은 라벨 `sky-700` + 제목 `h3` + 설명 |
| 추정치 안내 | 흰 배경 + `gray-200` 테두리, "**추정치 안내** · ..." |
| 판정 근거 카드 | 흰 배경 + `gray-200` 테두리, 핵심 수치 `metric-lg` |

## 8. 로고 사용

| 버전 | 쓰는 곳 |
|---|---|
| 심볼 + 워드마크 (가로형) | 로그인 화면, 발표 표지 |
| 워드마크 텍스트형 "미리봄" + `BEYOND ONLINE MONITORING` | 사이드바·앱 상단 (작은 크기) |
| 심볼 단독 | 파비콘, 앱 아이콘, 로딩 |

- **어두운 배경:** 흰색→하늘색 그라데이션 + 새싹 연두 잎 (V2.6)
- **밝은 배경:** 몸통 `navy-900` 단색 + 잎 `sprout-200`이 흰 배경에서 너무 연하므로 잎은 `#9BCB5A`로 진하게 한 버전을 따로 만든다 (제작 필요)
- 여백: 심볼 높이의 1/4 이상 비우기. 최소 크기: 심볼 24px, 가로형 96px
- 하지 말 것: 잎 색을 경보색으로 바꾸기, 늘리거나 기울이기, 그림자·외곽선 넣기, 사진 위에 바로 올리기

## 9. 접근성 체크

- 경보·혼잡 단계는 색 + 글자 라벨 둘 다
- 터치 영역 최소 44×44
- 차트에는 범례와 함께 핵심 수치를 문장으로도 제공 (판정 근거 문장)
