# 기능명세서

## 사용자 구분

| 구분 | 대상 | 쓰는 화면 | 하는 일 | 코드 |
|---|---|---|---|---|
| 관리자 | 부산시 재난안전 부서 | 경보 대시보드(웹) | 경보 확인, 대응 수준 결정, 별칭·병목 구간 입력, 시민 공지 | `admin` |
| 협력기관 | 구·군청, 시설 관리기관, 경찰 | 경보 알림(문자·메신저), 대시보드 링크 | 알림 수신, 현장 조치, 처리 결과·실측 회신 | `partner` |
| 시민 | 시민·방문객 | 혼잡 안내 화면(모바일 웹) | 예상 혼잡 확인, 방문 날짜·장소 조정 | `citizen` |

## 기능명세서

| 분류 | 기능명 | 설명 | MVP |
|---|---|---|---|
| admin-dashboard | 판정 현황 요약 | 매일 07시 판정 시각, 경보 단계 범례, 단계별 장소 수를 화면 맨 위에 표시 | ✅ |
| admin-dashboard | 급상승 장소 지도 | 부산 지도에 급상승 장소를 경보 단계별 색으로 표시, 누르면 장소 상세로 이동 | ✅ |
| admin-dashboard | 급상승 장소 목록 | 장소별 경보 단계, 급증 배수, 방문 의도 글 건수, 내일 예상 방문객 범위, 예상 병목 밀집도 표시. 새로 잡힌 장소에 '신규' 표시 | ✅ |
| admin-dashboard | 장소별 추이 그래프 | 검색 급증 배수, 실측 방문객, 1~3일 뒤 예측 방문객(중앙값·범위), 병목 기준선을 한 그래프로 표시 | ✅ |
| admin-dashboard | 판정 근거 보기 | 예측 병목 밀집도가 1㎡당 5명을 넘었는지와 해당 단계가 된 이유를 문장으로 표시. 현장 확인 전 값은 '추정치' 표시 | ✅ |
| admin-dashboard | 과거 사례 재현 | 날짜를 고르면 그날 07시까지 있던 자료만으로 판정을 다시 돌려 보여줌 (부캉이 시연용, 결과 [검증 예정]) | ✅ |
| admin-input | 별칭 등록 | '부캉이'처럼 새로 뜬 별칭을 실제 장소(북항친수공원)에 연결. 다음 날 판정부터 반영 | ✅ |
| admin-auth | 로그인·권한 구분 | 기관 계정(부산시 / 구·군청 / 시설 관리기관)으로 로그인. 부산시는 전체 장소 조회와 별칭 등록 등 입력 가능, 협력 기관은 관할 장소만 조회. 시민 화면은 로그인 없이 이용 | ✅ |
| citizen | 장소 검색 | 장소 이름이나 별칭('부캉이')으로 검색 | ✅ |
| citizen | 3일 예상 혼잡 | 오늘부터 3일간 날짜별 예상 혼잡을 '여유·보통·붐빔·매우 붐빔' 4단계로 표시 | ✅ |
| citizen | 추정치 안내 문구 | '예측에 기반한 추정치이며 실제와 다를 수 있음'을 화면에 항상 표시 | ✅ |
| pipeline | 자료 수집 | 매일 06시까지 전날 검색 지수(네이버 데이터랩), 날씨·휴일, SNS 글(Threads, 승인 후) 수집 | ✅ |
| pipeline | 방문 의도 분류 (AI) | LLM이 글마다 장소와 성격(가보겠다·후기·단순 언급·광고)을 뽑아 실제 방문 의도 글만 셈. 원문·작성자 정보는 바로 삭제 | ✅ |
| pipeline | 급증 탐지 | 장소별로 평소(계절·명절 보정) 대비 검색 급증 배수를 계산해 급상승 후보 선정 | ✅ |
| pipeline | 규모 예측 (AI) | 급증 배수, 증가 속도, 휴일, 날씨로 1~3일 뒤 방문객의 중앙값과 범위 예측 (LightGBM) | ✅ |
| pipeline | 경보 판정 | 07시에 예측 방문객을 병목 밀집도로 바꿔 1·2·3단계와 판정 보류 결정 | ✅ |
